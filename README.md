# Greylock Placement Services Website

A modern, SEO-optimized website for Greylock Placement Services LLC (G-P-S), specializing in navigating disability services and placement.

## Features

- **SEO Optimized**: Complete meta tags, Open Graph data, and structured data (JSON-LD)
- **AI Crawling Ready**: Comprehensive JSON-LD schemas for better AI understanding
- **Accessibility First**: WCAG compliant with skip links, ARIA labels, and semantic HTML
- **Jekyll Powered**: Built for GitHub Pages with Jekyll
- **Responsive Design**: Mobile-first approach with clean, modern styling
- **Performance Focused**: Optimized CSS and minimal JavaScript

## Local Development

1. Install Jekyll and dependencies:
```bash
bundle install
```

2. Run the development server:
```bash
bundle exec jekyll serve
```

3. Open http://localhost:4000 in your browser

## Deployment

This site is designed to be deployed on GitHub Pages. Simply push to the `main` or `gh-pages` branch and GitHub will automatically build and deploy the site.

## Structure

- `index.html` - Main homepage
- `_layouts/` - Jekyll layouts
- `_includes/` - Reusable components
- `assets/css/` - Stylesheets
- `_config.yml` - Jekyll configuration
- `sitemap.xml` - XML sitemap for search engines
- `robots.txt` - Crawler instructions
