# Image Assets Directory

This directory contains image assets for the Greylock Placement Services website.

## Required Images

### about-me.jpg
- **Description**: Professional headshot of Timothy R. Andenmatten
- **Usage**: Displayed on the About page in the Leadership section
- **Recommended size**: 800x800px or larger (will be resized via CSS)
- **Format**: JPG for optimal web performance

## How to Add the Image

1. Save the professional headshot image as `about-me.jpg`
2. Place it in this directory (`/assets/images/`)
3. Commit and push:
   ```bash
   git add assets/images/about-me.jpg
   git commit -m "Add Timothy R. Andenmatten professional headshot"
   git push origin Bear
   ```

The image is already referenced in the About page HTML and will display automatically once added.
